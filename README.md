# Professional Image Gallery 🖼️

A responsive image gallery built using HTML, CSS, and JavaScript. It allows users to explore images by category and view them in a larger preview.

## Features
- Image categories: All, Nature, City, and Travel
- Interactive image hover effects
- Full-screen image preview (Lightbox)
- Next and Previous image navigation
- Keyboard controls using arrow keys and Escape
- Responsive design for mobile, tablet, and desktop

## Technologies Used
- HTML5
- CSS3
- JavaScript
